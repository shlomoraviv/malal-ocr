# מלל — מתמונה לטקסט

אתר פשוט ומהיר שממיר תמונות לטקסט בעברית ובאנגלית, ישירות בדפדפן.
בלי התקנות, בלי הרשמה, ובלי ששום תמונה נשלחת לשרת.

🔗 **האתר החי:** https://shlomoraviv.github.io/malal-ocr/

## מה אפשר לעשות בו

- **הוספת תמונות** — גרירה, בחירת קבצים, צילום במצלמה, או הדבקת צילום מסך עם `Ctrl+V`.
- **תמלול OCR** — עברית + אנגלית (וגם ערבית, רוסית, צרפתית וספרדית), עם שיפור איכות אוטומטי לתמונות כהות/מטושטשות, קריאה מרובת מעברים ואריחים לתמונות עם טקסט קטן, וסינון רעש שמונע "קודים" ושורות כפולות.
- **עריכה על התמונה עצמה** — כל שורה בתמונה הופכת לשדה עריכה: כותבים ישר במקום. הגופן, המשקל, הגודל, הצבע ותיבת הטקסט נלקחים מהשורה המקורית ("כמו בתמונה (אוטומטי)"), כך שהטקסט החדש יושב במקום ובגודל של המקור. מאחורי השורה משוחזרים רק פיקסלי האותיות עצמן, כך שגם רקע תמונה, דוגמה או גרדיאנט ממשיכים ברצף בלי מלבן צבוע. אפשר גם לבחור גופן, משקל, צבע, יישור וגודל ידנית, ואז לייצא את התמונה הערוכה כ-PNG.
- **עריכה במקום** — לחיצה על "עריכה" (או לחיצה כפולה על הטקסט) וכותבים ישר על הטקסט שזוהה ברשימה.
- **מחיקה עם ביטול** — מחיקת מסמך או ניקוי הכול, עם כפתור "ביטול" מיידי.
- **חיפוש בכל המסמכים** — עם הדגשת ההתאמות וסינון הקבצים.
- **כלי ניקוי** — איחוד שורות לפסקה, ניקוי רווחים, החלפת כיוון (RTL/LTR), שכפול מסמך, תמלול מחדש.
- **ייצוא** — העתקת הכול, TXT, Markdown, CSV, גיבוי JSON, הדפסה/PDF ושיתוף.
- **שמירה אוטומטית** — הטקסטים והתמונות נשמרים מקומית בדפדפן (localStorage + IndexedDB).
- **מצב כהה/בהיר**, גודל טקסט מתכוונן, קיצורי מקלדת, עיצוב מותאם לנייד ולהדפסה.

## איך זה עובד

| רכיב | תיאור |
| --- | --- |
| `index.html` | כל האתר בקובץ אחד: HTML, CSS ו-JS, בלי תהליך build |
| Tesseract.js v7 | מנוע ה-OCR — נטען מ-CDN ועובד ב-Web Worker בתוך הדפדפן |
| שכבות שורה | מה-OCR נשמרים מיקומי השורות (bounding boxes) כדי למקם שדות עריכה מעל התמונה |
| זיהוי מדויק | קריאה ברזולוציה גבוהה (עד 3.2×), שכבת גוונים + שכבת בינאריזציה מקומית, איתור טקסט מפוזר באריחים חופפים, שיפור שורה-שורה, איחוד קריאות כפולות והרכבת השורה מתיבות המילים — כדי לשמור על רווחים בין מילים |
| סינון רעש | רשימת תווים אסורים, הסרת אסימוני פיסוק/לטינית זרים מגוף שורה עברית, ופסילת שורות דלות-אותיות בביטחון נמוך |
| התאמת גופן | כל שורה מושווית מול ספריית גופנים עבריים (Heebo, Rubik, Assistant, Noto Sans Hebrew, Frank Ruhl Libre ועוד): הגובה, המשקל, הפרופורציה וניגודיות הקווים נמדדים מול פיקסלי השורה, והמשפחה הדומיננטית במסמך משמשת כברירת מחדל לשאר השורות |
| דגימת צבע | צבע הדיו נדגם מגרעין האותיות (לא מההילה), והרקע מלמעלה ומלמטה — כדי לצבוע את הטקסט החדש ולהחליט מה כהה ומה רקע |
| שחזור רקע | מסכת פיקסלי האותיות (מודל רקע לפי אחוזונים לשורה ולעמודה, כולל זיהוי קוטביות לטקסט בהיר על כהה) + השלמה הרמונית עם מרקם משוקף מדפנות המסכה |
| localStorage | שמירת הטקסטים וההגדרות |
| IndexedDB | שמירת התמונות עצמן, כדי לאפשר תמלול מחדש גם אחרי רענון |

## הרצה מקומית

אין תלויות. פשוט פותחים את `index.html` בדפדפן, או מריצים שרת סטטי קטן:

```bash
python -m http.server 4173
```

כל הזיהוי רץ במחשב של המשתמש. התמונות והטקסטים לא נשלחים לשום שרת — רק ספריית הזיהוי עצמה נטענת מ-CDN.
